# Marketplace listing draft

**Name:** Christmas Code

**Summary:** An animated ASCII Christmas tree and falling snow behind your code.

**Description:** Add a quiet seasonal background to your editor: a rotating tree built from code-like characters, warm gold and amber garlands, glowing red and orange ornaments, presents, and gently falling snow. Share one continuous scene across split editors or give each pane its own tree. Tune opacity and optionally enable the effect when projects open. Animation pauses in inactive windows.

Enable via **Tools → Toggle Christmas Background**. Customize via **Settings → Tools → Christmas Code**. Everything runs locally; the plugin does not read or transmit document contents, collect analytics, or make network requests.
