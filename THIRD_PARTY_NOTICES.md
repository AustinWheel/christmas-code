# Third-party notices

Christmas Code's scene and icon are rendered from code. No reference video frames, third-party artwork, audio, or fonts are bundled.

The renderer selects an available system monospace font (Menlo, Consolas, DejaVu Sans Mono, Courier New, or Java's fallback); fonts remain supplied by the user's operating system.

The plugin uses Java and IntelliJ Platform APIs supplied by the host IDE. Development uses the Gradle Wrapper and IntelliJ Platform Gradle Plugin; tests use JUnit 4 and its dependencies. Those tools retain their respective licenses. The Gradle Wrapper scripts include their Apache 2.0 notices. No third-party runtime library is intended to be bundled in the plugin distribution.
