# Changelog

## 0.1.0

Initial release candidate:

- Animated ASCII Christmas tree, warm garlands, glowing ornaments, presents, and falling snow.
- Snow occlusion and a full-width ground surface.
- Shared backgrounds across splits, with optional per-pane scenes.
- Persistent opacity and layout settings.
- Opt-in automatic activation when a project opens.
- Pause animation in inactive windows and release resources when editors close.
